
## 🚀 Installation and Usage

### 1. Clone the Repository

```bash
git clone https://github.com/sakthiiiiiiii/Ecommerce-Customer-Behavior-Analytics.git
```

### 2. Navigate to the Project

```bash
cd Ecommerce-Customer-Behavior-Analytics
```

### 3. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

### 4. Run the Python Script

```bash
python Purchase_Behaviour.py
```

Ensure `Ecommerce_Transactions_2000.xlsx` is in the same project folder.
