
# 🛒 E-commerce Customer Behavior & Sales Analytics

## 📌 Project Overview

This project analyzes e-commerce transaction data using Python to uncover customer purchasing patterns, sales trends, product performance, and customer spending behavior.

The analysis focuses on transforming raw transactional data into meaningful business insights through data cleaning, Exploratory Data Analysis (EDA), customer segmentation, and data visualization.

## 🎯 Project Objectives

- Analyze 2,000 e-commerce transactions.
- Identify customer purchasing patterns.
- Evaluate customer spending behavior.
- Discover popular products and categories.
- Analyze monthly sales performance.
- Segment customers based on spending and purchase frequency.
- Generate actionable business insights.

## 🛠️ Technologies Used

| Technology | Purpose |

| NumPy | Numerical operations |

## 📊 Dataset

**Total Records:** 2,000 transactions

The dataset contains e-commerce transaction information used to examine customer activity, purchasing behavior, and sales performance.

## 🔍 Project Workflow

### 1. Data Collection
- Load the Excel dataset using Pandas.
- Inspect columns and data types.
- Understand the dataset structure.

### 2. Data Cleaning
- Identify missing values.
- Check duplicate records.
- Validate numerical fields.
- Prepare transaction data for analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyze total sales and transactions.
- Examine customer purchasing frequency.
- Evaluate product popularity.
- Identify sales trends over time.
- Analyze customer spending patterns.

### 4. Customer Segmentation
Customers are categorized based on:
- Total spending
- Purchase frequency
- Transaction activity

Rule-based segmentation helps identify high-value, medium-value, and low-value customers.

### 5. Data Visualization
The project uses Matplotlib and Seaborn to visualize:
- Monthly sales trends
- Customer spending distribution
- Product performance
- Customer segments
- Purchasing frequency

## 🚀 Installation

### Step 1: Clone the Repository

```bash
git clone https://github.com/sakthiiiiiiii/Ecommerce-Customer-Behavior-Analytics.git
```

### Step 2: Navigate to the Project

```bash
cd Ecommerce-Customer-Behavior-Analytics
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Analysis

```bash
python Purchase_Behaviour.py
```

Ensure the Excel dataset is available in the project directory.
